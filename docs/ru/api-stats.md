# Статистика трекера

Функции статистики предоставляют доступ к отчётам по лидам и кликам.

<a id="leads"></a>
## Список лидов

**URL вебмастера**: `https://domain.com/api/tracker/leads.json?id={token}`

**URL команды**: `https://domain.com/api/gangs/leads.json?id={token}`

Функция извлекает список лидов и выдаёт его в виде ассоциативного массива в поле `leads`. Параметры можно передавать через GET или POST (`form-urlencoded` или JSON). Для постраничной навигации используйте параметры `show` и `page`; без `show` возвращаются сразу все подходящие лиды. Не рекомендуется выгружать больше тысячи лидов за раз — если вы получили ошибку 500, значит на ваш запрос не хватило памяти, уменьшите период запроса или используйте постраничную навигацию. Используйте параметры `sort` и `order` для управления порядком возвращаемых лидов; без `sort` лиды возвращаются в естественном порядке (порядке вставки).

Функция может принимать на вход следующие GET- или POST-параметры фильтрации:

| Поле | Описание |
| --- | --- |
| `from` | Дата начала отчёта в формате `ГГГГ-ММ-ДД` и часовом поясе трекера. |
| `to` | Дата окончания отчёта в формате `ГГГГ-ММ-ДД` и часовом поясе трекера. |
| `ufrom` | Дата начала отчёта в формате Unix Timestamp. |
| `uto` | Дата окончания отчёта в формате Unix Timestamp. |
| `status` | Символьный статус лида (см. ниже) |
| `geo` | Двухбуквенный ISO-код страны лида. |
| `flow` | Символьный идентификатор потока. |
| `way` | Числовой идентификатор пути. |
| `click` | Символьный идентификатор клика. |
| `site` | Числовой идентификатор сайта. |
| `goal` | Символьный идентификатор цели. |
| `filter` | Результат работы фильтров (см. ниже) |
| `domain` | Домен, с которого был отправлен лид. |
| `ip` | IP-адрес лида. |
| `utm_source` | Значение метки **UTM Source**. |
| `utm_campaign` | Значение метки **UTM Campaign**. |
| `utm_content` | Значение метки **UTM Content**. |
| `utm_term` | Значение метки **UTM Term**. |
| `utm_medium` | Значение метки **UTM Medium**. |
| `subid` | Значение метки **SubID**. |
| `customer` | Значение метки **Клиент**. |
| `sort` | Поле для сортировки лидов (см. ниже). Без него лиды возвращаются в естественном порядке (порядке вставки). |
| `order` | Направление сортировки: `asc` или `desc`. По умолчанию `desc`. |
| `user` | ID пользователя в команде. |
| `show` | Количество лидов на странице. Включает постраничную навигацию. Без него возвращаются все подходящие лиды, а в ответе `show` равен `-1`. |
| `page` | Номер страницы, начиная с `1` (используется вместе с `show`). |

Символьные статусы лида (`status`):

- `new` - новые лиды.
- `hold` - лиды в холде.
- `approve` - подтверждённые лиды.
- `cancel` - отклонённые лиды.
- `trash` - лиды в треше.
- `valid` - валидные лиды (виртуальный статус, всё кроме треша).
- `wait` - лиды в ожидании (виртуальный статус, новые и холд).
- `good` - удачные лиды (виртуальный статус, холд и аппрув).
- `bad` - неудачные лиды (виртуальный статус, отмена и треш).

Результат работы фильтров (`filter`):

- `0` - целевые визиты.
- `1` - блокировка: бот.
- `2` - блокировка: чёрный список.
- `3` - блокировка: страна.
- `4` - блокировка: язык.
- `5` - блокировка: кампания фильтрации.

Поля, доступные для `sort` (`sort`):

- `id` — ID лида (значение по умолчанию; также используется при недопустимом значении параметра).
- `time` / `date` — время поступления лида.
- `status` — статус лида.
- `filter` — результат работы фильтров.
- `goal` — ID цели.
- `price` — цена лида.
- `cost` — сумма чека лида.
- `geo` — страна лида.
- `flow` — ID потока.
- `way` — ID пути.
- `site` — ID сайта.

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `leads` | Массив лидов, состав полей разобран далее. |
| `page` | Текущий номер страницы (дублирует запрос, по умолчанию `1`). |
| `show` | Размер страницы или `-1`, если постраничная навигация не запрашивалась. |
| `total` | Общее количество подходящих лидов. При постраничной навигации это полный счётчик, иначе — количество возвращённых лидов. |
| `error` | Код ошибки для статуса `error` (см. ниже) |

Коды ошибок:

- `access` - вы пытаетесь получить доступ к данным, которые вам не принадлежат.
- `payment-required` - ваша подписка истекла, [продлите подписку](/payments).

<a id="stats"></a>
## Статистика по кликам

**URL вебмастера**: `https://domain.com/api/tracker/stats.json?id={token}`

**URL команды**: `https://domain.com/api/gangs/stats.json?id={token}`

Функция собирает общую статистику по количеству кликов и лидов с разбивкой по целям за выбранный период по указанному критерию. Параметры можно передавать через GET или POST (`form-urlencoded` или JSON). Для постраничной навигации используйте параметры `show` и `page`. Используйте параметры `sort` и `order` для управления порядком строк группировки; сортировка применяется ко всему результату до его разбиения на страницы, поэтому постраничные результаты остаются корректно упорядоченными на границах страниц.

Функция может принимать на вход следующие GET- или POST-параметры фильтрации:

| Поле | Описание |
| --- | --- |
| `from`* | Дата начала отчёта в формате `ГГГГ-ММ-ДД` (обязательно). |
| `to`* | Дата окончания отчёта в формате `ГГГГ-ММ-ДД` (обязательно). |
| `item`* | Элемент, по которому группируется статистика (обязательно, см. ниже)  |
| `geo` | Двухбуквенный ISO-код страны лида. |
| `flow` | Символьный идентификатор потока. |
| `way` | Числовой идентификатор пути. |
| `site` | Числовой идентификатор сайта. |
| `filter` | Результат работы фильтров (см. ниже) |
| `hour` | Час поступления лида (число от 0 до 23). |
| `mobile` | Тип трафика: `0` для десктоп-трафика или `1` для мобильного трафик. |
| `os` | Операционная система (см. ниже) |
| `browser` | Браузер (см. ниже) |
| `domain` | Домен, с которого был отправлен лид. |
| `ip` | IP-адрес лида. |
| `utm_source` | Значение метки UTM Source. |
| `utm_campaign` | Значение метки UTM Campaign. |
| `utm_content` | Значение метки UTM Content. |
| `utm_term` | Значение метки UTM Term. |
| `utm_medium` | Значение метки UTM Medium. |
| `customer` | Значение метки Клиент. |
| `subid` | Значение метки `subid`. |
| `sort` | Поле для сортировки строк группировки: `name`, `id`, `click`, `unique`, `spend`, `next`, `cn`, `ch`, `ca`, `cc`, `ct`, `cv`, `total`, `mt`, `mh`, `ma`, `mmt`, `mmh`, `mma`, `mct`, `mch`, `mca`, `ur`, `cr`, `crt`, `epc`, `epl`, `appr`, `app`, `per`, `cpc`, `cpa`, `cpv`, `cpl`, `profit` или `roi` — те же названия, что и у полей объекта `stats`/`total` ниже (см. ниже). Любое другое значение приводит к сортировке по `name`. Без `sort` строки возвращаются в естественном порядке (порядке вставки). |
| `order` | Направление сортировки: `asc` или `desc`. По умолчанию `desc`. |
| `show` | Количество строк группировки на странице. Включает постраничную навигацию. Без него возвращаются все строки, а в ответе `show` равен `-1`. |
| `page` | Номер страницы, начиная с `1` (используется вместе с `show`). |

Элементы, по которым группируется статистика (`item`):

- `date` - дата поступления клика и лида.
- `hour` - час поступления клика и лида.
- `flow` - поток.
- `way` - путь.
- `site` - сайт.
- `filter` - результаты фильтрации.
- `geo` - страна.
- `mobile` - устройство.
- `os` - операционная система.
- `browser` - браузер.
- `ip` - IP-адрес.
- `utmd` - домен.
- `utmu` - клиент.
- `subid` - метка SubID.
- `utms` - метка UTM Source.
- `utmc` - метка UTM Campaign.
- `utmn` - метка UTM Content.
- `utmt` - метка UTM Term.
- `utmm` - метка UTM Medium.
- `user` - ID пользователя в команде.

Результаты работы фильтров (`filter`):

- `0` - целевые визиты.
- `1` - блокировка: бот.
- `2` - блокировка: чёрный список.
- `3` - блокировка: страна.
- `4` - блокировка: язык.
- `5` - блокировка: кампания фильтрации.

Операционные системы (`os`):

- `0` - Other
- `1` - Windows
- `2` - MacOS
- `3` - Linux
- `4` - iOS
- `5` - Android
- `6` - Windows Mobile
- `7` - Symbian
- `8` - BlackBerry

Браузеры (`browser`):

- `0` - Other
- `1` - Chrome
- `2` - Firefox
- `3` - MSIE
- `4` - Safari
- `5` - Opera
- `6` - Edge
- `7` - Facebook
- `8` - Instagram
- `9` - Tik-Tok
- `10` - WebView
- `11` - Bot

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `stats` | Массив результатов статистики, состав полей разобран далее. |
| `total` | Суммарные результаты по всему запросу. |
| `page` | Текущий номер страницы (дублирует запрос, по умолчанию `1`). |
| `show` | Размер страницы или `-1`, если постраничная навигация не запрашивалась. |
| `items` | Общее количество строк группировки до постраничной разбивки (используйте для расчёта числа страниц). |
| `error` | Код ошибки для статуса `error` (см. ниже) |

Коды ошибок:

- `access` - вы пытаетесь получить доступ к данным, которые вам не принадлежат.
- `no-item` - не указан критерий, по которому необходимо собрать статистику.
- `no-from` - не указана дата начала периода статистики.
- `no-to` - не указана дата окончания периода статистики.
- `payment-required` - ваша подписка истекла, [продлите подписку](/payments).

## Список кликов

**URL вебмастера**: `https://domain.com/api/tracker/clicks.json?id={token}`

**URL команды**: `https://domain.com/api/gangs/clicks.json?id={token}`

Функция извлекает список необработанных кликов — всех визитов, попавших в поток, независимо от того, был ли по ним создан лид — и выдаёт его в виде ассоциативного массива в поле `data` (обратите внимание: именно `data`, а не `leads`, как в функции списка лидов выше). Параметры можно передавать через GET или POST (`form-urlencoded` или JSON). Для постраничной навигации используйте параметры `show` и `page`; без `show` возвращаются сразу все подходящие клики (с ограничением в 10000 строк). Используйте параметры `sort` и `order` для управления порядком возвращаемых кликов; без `sort` клики возвращаются в естественном порядке (порядке вставки).

Функция может принимать на вход следующие GET- или POST-параметры фильтрации:

| Поле | Описание |
| --- | --- |
| `from` | Дата начала отчёта в формате `ГГГГ-ММ-ДД` и часовом поясе трекера. |
| `to` | Дата окончания отчёта в формате `ГГГГ-ММ-ДД` и часовом поясе трекера. |
| `ufrom` | Дата начала отчёта в формате Unix Timestamp. |
| `uto` | Дата окончания отчёта в формате Unix Timestamp. |
| `geo` | Двухбуквенный ISO-код страны клика. |
| `ip` | IP-адрес клика. |
| `flow` | Символьный идентификатор потока. |
| `way` | Числовой идентификатор пути. |
| `site` | Числовой идентификатор сайта. |
| `offer` | Числовой идентификатор оффера. |
| `click` | Символьный идентификатор клика. |
| `filter` | Результат работы фильтров (см. ниже) |
| `mobile` | Тип трафика: `0` для десктоп-трафика или `1` для мобильного трафика. |
| `os` | Операционная система (см. ниже) |
| `browser` | Браузер (см. ниже) |
| `unique` | Числовой флаг: `1` только для уникальных кликов, `0` только для повторных. |
| `next` | Числовой флаг: `1` для кликов, перешедших на второй шаг, `0` для остальных. |
| `domain` | Домен, с которого пришёл клик. |
| `utm_source` | Значение метки **UTM Source**. |
| `utm_campaign` | Значение метки **UTM Campaign**. |
| `utm_content` | Значение метки **UTM Content**. |
| `utm_term` | Значение метки **UTM Term**. |
| `utm_medium` | Значение метки **UTM Medium**. |
| `subid` | Значение метки **SubID**. |
| `customer` | Значение метки **Клиент**. |
| `sort` | Поле для сортировки кликов (см. ниже). Без него клики возвращаются в естественном порядке (порядке вставки). |
| `order` | Направление сортировки: `asc` или `desc`. По умолчанию `desc`. |
| `user` | ID пользователя в команде. |
| `show` | Количество кликов на странице. Включает постраничную навигацию. Без него возвращаются все подходящие клики (с ограничением в 10000 строк), а в ответе `show` равен `-1`. |
| `page` | Номер страницы, начиная с `1` (используется вместе с `show`). |

Результат работы фильтров (`filter`):

- `0` - целевые визиты.
- `1` - блокировка: бот.
- `2` - блокировка: чёрный список.
- `3` - блокировка: страна.
- `4` - блокировка: язык.
- `5` - блокировка: кампания фильтрации.

Операционные системы (`os`):

- `0` - Other
- `1` - Windows
- `2` - MacOS
- `3` - Linux
- `4` - iOS
- `5` - Android
- `6` - Windows Mobile
- `7` - Symbian
- `8` - BlackBerry

Браузеры (`browser`):

- `0` - Other
- `1` - Chrome
- `2` - Firefox
- `3` - MSIE
- `4` - Safari
- `5` - Opera
- `6` - Edge
- `7` - Facebook
- `8` - Instagram
- `9` - Tik-Tok
- `10` - WebView
- `11` - Bot

Поля, доступные для `sort` (`sort`):

- `id` — ID клика (значение по умолчанию; также используется при недопустимом значении параметра).
- `time` / `date` — время клика.
- `filter` — результат работы фильтров.
- `price` — цена клика.
- `geo` — страна клика.
- `mobile` — тип устройства.
- `os` — операционная система.
- `browser` — браузер.
- `flow` — ID потока.
- `way` — ID пути.
- `site` — ID сайта.

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `data` | Массив кликов, состав полей разобран далее. |
| `page` | Текущий номер страницы (дублирует запрос, по умолчанию `1`). |
| `show` | Размер страницы или `-1`, если постраничная навигация не запрашивалась. |
| `total` | Общее количество подходящих кликов. При постраничной навигации это полный счётчик, иначе — количество возвращённых кликов. |
| `error` | Код ошибки для статуса `error` со значением из списка:

`payment-required` - ваша подписка истекла, [продлите подписку](/payments). |
