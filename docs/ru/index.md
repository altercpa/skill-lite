# Помощь и документация

AlterCPA Lite - это серверный трекер для арбитража трафика. Мы предоставляем вам инструменты для работы с трафиком и локальными сайтами, умного сплит-тестирования, фильтрации визитов, анатилики трафика по целям. Поддерживается трекинг как через серверные постбеки, так и через клиентские пиксели.

::: card
### Краткое содержание инструкции

1. **Создаём** свой первый [поток](flows.md) или [сплит-тест](split.md).
2. Паркуем [домены](domain.md) для заливки трафика.
3. Берём **файл клиента** или **ссылку потока** и заливаем трафик.
4. Анализируем [статистику](stats.md) и считаем свою прибыль.

[Всё ясно, поехали!](/login)
:::
