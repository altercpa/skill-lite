# Хранилище сайтов

API хранилища сайтов позволяет управлять локальными сайтами трекера: загружать ZIP-архивы лендингов и прелендингов, зеркалировать сайты по URL, изменять их свойства, удалять и скачивать архивы. Сайты в хранилище используются в [путях потоков](api-flows.md) как целевые страницы и в трафикбэке. Каждый сайт получает короткий обфусцированный путь вида `{2hex}/{enc-id}` и доступен по домену хранилища.

Хранилище может быть системным (общим для трекера), пользовательским или командным. Операции с сайтами всегда направляются на хранилище, актуальное для контекста запроса: командное имеет приоритет над пользовательским, пользовательское — над системным.

<a id="siteslist"></a>
## Список сайтов

**URL вебмастера**: `https://domain.com/api/sites/list.json?id={token}`

**URL команды**: `https://domain.com/api/sites/list.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/sites/list.json?id={token}&scope=admin`

Функция возвращает список сайтов с поддержкой фильтрации и пагинации. Все фильтры объединяются по условию AND. При `scope=admin` проверка биллинга не выполняется.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `scope` | Рабочее пространство: `user` (по умолчанию), `gang`/`team`, `admin`/`sys`. |
| `user` | Для `scope=gang` или `scope=admin`: ID конкретного участника команды или пользователя для фильтрации. |
| `gang` | Для `scope=admin`: ID команды для фильтрации. |
| `uid` | Точный поиск по ID сайта. |
| `glue` | Фильтр по маркеру видимости (для командных сайтов, см. ниже). |
| `offer` | Фильтр по ID оффера. |
| `search` | Поиск по названию сайта. |
| `page` | Страница результатов (≥ 1). По умолчанию — 1. |
| `show` | Размер страницы. По умолчанию — 0 (вернуть все записи без ограничения). |

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже). |
| `total` | Общее количество записей, соответствующих фильтрам. При `show > 0` вычисляется отдельным запросом. |
| `page` | Текущая страница. |
| `show` | Размер страницы. |
| `data` | Словарь сайтов, ключи — ID сайта (см. ниже). |

Коды ошибок:

- `scope` — не пройдена проверка прав рабочего пространства (неверный scope, нет прав тимлида или администратора).
- `unpaid` — истёк или не оплачен доступ к трекеру (только для `scope=user` и `scope=gang`).

Состав записи в `data`:

| Поле | Описание |
| --- | --- |
| `uid` | Числовой идентификатор сайта. |
| `user` | ID владельца-пользователя для личного сайта; `0` для gang-сайта. |
| `gang` | ID команды; `0` для личного сайта. |
| `glue` | Маркер видимости для gang-сайта (см. ниже); `0` для личного сайта. |
| `name` | Название сайта. |
| `path` | Путь сайта на хранилище в формате `{2hex}/{enc-id}`. |

Значения маркера видимости (`glue`) для gang-сайтов:

- `0` — сайт скрыт от команды (виден только администратору команды).
- `-1` — публичный сайт для всей команды.
- `>0` — сайт привязан к конкретному участнику команды (виден только ему и администраторам команды).

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "total": 2,
    "page": 1,
    "show": 0,
    "data": {
        "42": {
            "uid": 42,
            "user": 7,
            "gang": 0,
            "glue": 0,
            "name": "Landing about insurance",
            "path": "ab/cm6gh1"
        },
        "43": {
            "uid": 43,
            "user": 0,
            "gang": 3,
            "glue": -1,
            "name": "Team public prelanding",
            "path": "f2/dkp8n3"
        }
    }
}
```

**Пример ошибочного ответа сервера:**

```json
{
    "status": "error",
    "error": "scope"
}
```

<a id="sitesadd"></a>
## Загрузить сайт

**URL вебмастера**: `https://domain.com/api/sites/add.json?id={token}`

**URL команды**: `https://domain.com/api/sites/add.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/sites/add.json?id={token}&scope=admin`

Функция создаёт новый сайт в хранилище. В зависимости от переданных параметров на хранилище выполняется одно из трёх действий: распаковка ZIP-архива, зеркальное скачивание по URL через httrack или создание пустой папки. Операция с БД и операция с хранилищем независимы: если хранилище недоступно, запись о сайте всё равно будет создана, но файлы на диске могут не появиться.

Зеркальное скачивание (`url`) выполняется в фоновом режиме без уведомлений. Технические лимиты httrack: до 100 МБ данных и до 10 минут на выполнение. Если переданы оба параметра (`archive` и `url`), приоритет имеет `archive`.

Запрос должен быть отправлен методом POST с `Content-Type: multipart/form-data` при передаче файла, либо стандартным запросом GET/POST без файла.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `name`* | Название сайта. Обязательный параметр. |
| `scope` | Рабочее пространство: `user` (по умолчанию), `gang`/`team`, `admin`/`sys`. |
| `glue` | Маркер видимости для gang-сайта (см. значения в [списке сайтов](#siteslist)). Актуален при `scope=gang` или `scope=admin` с указанием `gang`. По умолчанию — 0 (скрыт). |
| `user` | Для `scope=admin` без `gang`: ID пользователя-владельца нового сайта. |
| `gang` | Для `scope=admin`: ID команды-владельца нового сайта. |
| `archive` | ZIP-архив сайта (поле `archive` в `multipart/form-data`). После загрузки хранилище распакует архив в папку сайта. |
| `url` | URL сайта для зеркального скачивания через httrack. Игнорируется, если передан `archive`. |

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже). |
| `data` | Данные созданного сайта (см. ниже). |

Коды ошибок:

- `scope` — не пройдена проверка прав рабочего пространства.
- `unpaid` — истёк или не оплачен доступ к трекеру (только для `scope=user` и `scope=gang`).
- `user-required` — для `scope=admin` не передан ни `user`, ни `gang`.
- `wrong-glue` — переданный `glue` (значение `>0`) не принадлежит выбранной команде.
- `add` — не удалось создать сайт: пустое название, ошибка базы данных.

Состав поля `data`:

| Поле | Описание |
| --- | --- |
| `id` | Числовой идентификатор созданного сайта. |
| `user` | ID владельца-пользователя; `0` для gang-сайта. |
| `gang` | ID команды; `0` для личного сайта. |
| `glue` | Маркер видимости (см. [список сайтов](#siteslist)). |
| `name` | Название сайта. |
| `path` | Путь сайта на хранилище в формате `{2hex}/{enc-id}`. |

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "data": {
        "id": 42,
        "user": 7,
        "gang": 0,
        "glue": 0,
        "name": "Landing about insurance",
        "path": "ab/cm6gh1"
    }
}
```

**Пример ошибочного ответа сервера:**

```json
{
    "status": "error",
    "error": "add"
}
```

<a id="sitesedit"></a>
## Изменить сайт

**URL вебмастера**: `https://domain.com/api/sites/edit.json?id={token}`

**URL команды**: `https://domain.com/api/sites/edit.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/sites/edit.json?id={token}&scope=admin`

Функция изменяет название и/или маркер видимости сайта, а также позволяет перезаписать его содержимое, загрузив новый ZIP-архив или указав новый URL для зеркалирования. Если ни `archive`, ни `url` не переданы, запрос на хранилище не отправляется — обновляются только поля в базе данных. При передаче `archive` или `url` содержимое сайта на хранилище полностью перезаписывается.

Операции с БД и хранилищем независимы: если хранилище недоступно, изменения в БД всё равно будут сохранены.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `uid`* | Идентификатор сайта. Обязательный параметр. Принимается также в поле `sid`. |
| `scope` | Рабочее пространство: `user` (по умолчанию), `gang`/`team`, `admin`/`sys`. |
| `name` | Новое название сайта. Если не передано, название остаётся прежним. |
| `glue` | Новый маркер видимости для gang-сайта (см. значения в [списке сайтов](#siteslist)). Актуален при `scope=gang` или `scope=admin`. Применяется, только если параметр фактически присутствует в запросе; если не передан, текущий маркер сохраняется. |
| `archive` | Новый ZIP-архив сайта (поле `archive` в `multipart/form-data`). Перезаписывает содержимое. |
| `url` | Новый URL для зеркального скачивания. Игнорируется, если передан `archive`. |

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже). |
| `data` | Данные сайта после изменения (состав — как в [загрузке сайта](#sitesadd)). |

Коды ошибок:

- `scope` — не пройдена проверка прав рабочего пространства.
- `unpaid` — истёк или не оплачен доступ к трекеру (только для `scope=user` и `scope=gang`).
- `no-id` — не передан идентификатор сайта (`uid`/`sid`).
- `bad-id` — сайт с указанным идентификатором не найден.
- `auth` — недостаточно прав: при `scope=user` сайт принадлежит другому пользователю или команде; при `scope=gang` сайт принадлежит другой команде.
- `wrong-glue` — переданный `glue` (значение `>0`) не принадлежит выбранной команде.
- `edit` — не удалось сохранить изменения: ошибка базы данных или у сайта нет владельца.

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "data": {
        "id": 42,
        "user": 7,
        "gang": 0,
        "glue": 0,
        "name": "Updated landing",
        "path": "ab/cm6gh1"
    }
}
```

**Пример ошибочного ответа сервера:**

```json
{
    "status": "error",
    "error": "bad-id"
}
```

## Удалить сайт

**URL вебмастера**: `https://domain.com/api/sites/del.json?id={token}`

**URL команды**: `https://domain.com/api/sites/del.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/sites/del.json?id={token}&scope=admin`

Функция удаляет запись о сайте из базы данных и папку с файлами сайта на хранилище. Операции независимы: если хранилище недоступно, запись из БД всё равно будет удалена, а файлы на диске останутся. После удаления сайта связанные с ним пути потоков сохраняют ссылки на несуществующий идентификатор — рекомендуется заблаговременно обновить соответствующие [потоки](api-flows.md).

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `uid`* | Идентификатор сайта. Обязательный параметр. Принимается также в поле `sid`. |
| `scope` | Рабочее пространство: `user` (по умолчанию), `gang`/`team`, `admin`/`sys`. |

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже). |
| `data` | Данные удалённого сайта (состав — как в [загрузке сайта](#sitesadd)). |

Коды ошибок:

- `scope` — не пройдена проверка прав рабочего пространства.
- `unpaid` — истёк или не оплачен доступ к трекеру (только для `scope=user` и `scope=gang`).
- `no-id` — не передан идентификатор сайта (`uid`/`sid`).
- `bad-id` — сайт с указанным идентификатором не найден.
- `auth` — недостаточно прав: при `scope=user` сайт принадлежит другому пользователю или команде; при `scope=gang` сайт принадлежит другой команде.
- `del` — не удалось удалить сайт: ошибка базы данных или нет прав на сайт.

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "data": {
        "id": 42,
        "user": 7,
        "gang": 0,
        "glue": 0,
        "name": "Landing about insurance",
        "path": "ab/cm6gh1"
    }
}
```

**Пример ошибочного ответа сервера:**

```json
{
    "status": "error",
    "error": "auth"
}
```

<a id="sitesdownload"></a>
## Скачать сайт

**URL вебмастера**: `https://domain.com/api/sites/download.json?id={token}`

**URL команды**: `https://domain.com/api/sites/download.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/sites/download.json?id={token}&scope=admin`

Функция возвращает ZIP-архив со всеми файлами сайта. В случае успеха ответ содержит бинарный поток данных, а не JSON. В случае ошибки ответ возвращается в стандартном JSON-формате.

При `scope=admin` проверка принадлежности сайта не выполняется — администратор может скачать любой сайт без указания `user` или `gang`.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `uid`* | Идентификатор сайта. Обязательный параметр. Принимается также в поле `sid`. |
| `scope` | Рабочее пространство: `user` (по умолчанию), `gang`/`team`, `admin`/`sys`. |

**Успешный ответ** — HTTP 200 с заголовками:

```
Content-Type: application/octet-stream
Content-Disposition: attachment; filename=site.zip
```

Тело ответа — бинарный ZIP-архив файлов сайта.

**Ошибочный ответ** — JSON:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `error`. |
| `error` | Код ошибки (см. ниже). |

Коды ошибок:

- `scope` — не пройдена проверка прав рабочего пространства.
- `unpaid` — истёк или не оплачен доступ к трекеру (только для `scope=user` и `scope=gang`).
- `no-id` — не передан идентификатор сайта (`uid`/`sid`).
- `bad-id` — сайт с указанным идентификатором не найден.
- `auth` — недостаточно прав: при `scope=user` сайт принадлежит другому пользователю или команде; при `scope=gang` сайт принадлежит другой команде. Для `scope=admin` эта ошибка не возвращается.
- `download` — не удалось получить архив с хранилища (хранилище недоступно или архив не создан).

**Пример ошибочного ответа сервера:**

```json
{
    "status": "error",
    "error": "download"
}
```
