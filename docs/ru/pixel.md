# Трекинг через пиксели

Конверсии в трекере AlterCPA Lite могут отслеживаться не только через [серверные постбеки](postback.md), но и через клиентские пиксели. Это позволяет устанавливать код отслеживания на обычные HTML-сайты, например, вставлять на страницы "Спасибо".

## Как работает пиксель?

В момент перехода по вашей трекинг-ссылке, формируется ID клика. Этот идентификатор записывается в cookie браузера пользователя с привязкой к вашему потоку. Визит пользователя с таким идентификатором на страницу с пикселем создаст конверсию, привязанную к этому клику.

> **Очень важно!** Такой вариант отслеживания является небезопасным с точки зрения накрутки. Любой желающий может найти адрес вашего пикселя, совершив тестовый заказ, и позднее нагнать посетителей, получить ID кликов и создать ложные конверсии. Не рекомендуется использовать этот подход там, где нужна высокая точность и безопасность отслеживания.

## Как вставляется пиксель?

Запросы к пикселю можно выполнять с помощью вставки картинки или через AJAX. Наиболее простым вариантом будет вставка картинки пикселя в код страницы. Образец такой вставки показывается в настройках потока.

![Настройки постбека](assets/img/ru-postback.png)

Домен, на котором размещается пиксель, должен совпадать с доменом, по которому был выполнен переход. В случае успешного срабатывания пикселя, с ответом выдаётся статус `200`, в случае возникновения ошибки - статус `418`.

## Общий формат ссылки

Ссылка для пикселя состоит из домена, кода потока и формата пикселя:

```
https://domain.com/code/pixel.gif
```

Где вместо `domain.com` указывается ваш домен, вместо `code` - символьный код потока, а вместо `pixel` - вид пикселя: `pixel` для лида или `success` для аппрува, формат: `json`, `png` или `gif`

## Вставка картинки

Пиксель для создания обычного лида в формате GIF:

```html
<img src="https://track.altercpa.one/abcd/pixel.gif" alt="" width="1" height="1" />
```

Пиксель для создания обычного лида в формате PNG:

```html
<img src="https://track.altercpa.one/abcd/pixel.png" alt="" width="1" height="1" />
```

Пиксель для создания подтверждённого лида в формате GIF:

```html
<img src="https://track.altercpa.one/abcd/success.gif" alt="" width="1" height="1" />
```

Пиксель для создания подтверждённого лида в формате PNG:

```html
<img src="https://track.altercpa.one/abcd/success.png" alt="" width="1" height="1" />
```

## Запрос через JavaScript

Ссылка для создания обычного лида:

```
https://track.altercpa.one/abcd/pixel.json
```

Ссылка для создания подтверждённого лида:

```
https://track.altercpa.one/abcd/success.json
```

Ответы скрипта совпадают с ответами стандартно [API постбек-запросов](api-tracker.md#postback).

## Параметры пикселя

В ссылке пикселя можно сразу указать дополнительные параметры, которые поменяют его поведение. Параметры указываются после знака вопроса, как в обычной ссылке:

```
https://track.altercpa.one/abcd/pixel.gif?status=approve&goal=dep
```

Доступные параметры:

- `status` - статус лида: `new`, `hold`, `approve`, `cancel`, `trash`. Использование пикселя `success` аналогично добавлению `status=approve`.
- `goal` - символьный идентификатор цели.
- `uid` - уникальный ID лида на стороне рекламодателя.
- `price` - сумма выплаты за лид.
- `currency` - трехбуквенный ISO-код валюты, в которой выполняется выплата.
- `name`, `phone`, `email`, `comment`, `geo`, `ip` - данные лида.
- `utm_source`, `utm_campaign`, `utm_content`, `utm_term`, `utm_medium`, `subid`, `domain`, `adid`, `data1`, `data2` - метки лида, которые заменяют полученные из клика.

Параметры всегда передаются только в GET-запросе. Назначение и состав параметров совпадает с [отправкой обычного постбека](api-tracker.md#postback).
