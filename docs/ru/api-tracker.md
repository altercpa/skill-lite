# Интеграция с трекером

Функции интеграции отвечают за подключение сторонних сервисов и передачу данных о конверсиях.

<a id="postback"></a>
## Постбек

**URL**: `https://domain.com/postbacks/{key}?click={click}`

**API URL вебмастера**: `https://domain.com/api/tracker/postback.json?id={token}&click={click}`

**API URL команды**: `https://domain.com/api/gangs/postback.json?id={token}&click={click}`

Самая главная функция взаимодействия с трекером. Создаёт новый или изменяет существующий лид по отправленным ID клика или потока. Вы можете использовать два варианта вызова:

- **Стандартный вариант работы**: с параметром `click`. Данные для лида берутся из ID клика. Используется по умолчанию, рекомендуется применять именно такой подход.
- **Резервный вариант работы**: с параметрами `flow` и `subid`. Данные для лида берутся из ID потока, уникальность запроса определяется по параметру `subid`. Подходит для случаев, где нет понятия клика и перехода по ссылке, например для интеграции приложений.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `click` | Символьный идентификатор клика. |
| `flow` | Символьный идентификатор потока. |
| `uid` | Уникальный идентификатор лида на стороне рекламодателя. |
| `status` | Статус лида, оптимально: `new`, `hold`, `approve`, `cancel`, `trash`. |
| `goal` | Символьный идентификатор [цели](goal.md). |
| `create` | Создавать новый лид при каждом получении постбека. Укажите значение `1`. |
| `price` | Цена лида (отчисление). |
| `addprice` | Добавить сумму к текущей цене лида. |
| `currency` | Трёхсимвольный ISO-код валюты лида, по умолчанию `usd`. |
| `convert` | ISO-код валюты, в которую нужно конвертировать сумму выплаты, по умолчанию не используется. |
| `cost` | Сумма чека лида (не отчисление!). |
| `addcost` | Добавить сумму к текущему чеку лида. |
| `costcur` | Трёхсимвольный ISO-код валюты суммы чека, по умолчанию `usd`. |
| `costconv` | ISO-код валюты, в которую нужно конвертировать сумму чека, по умолчанию не используется. |
| `name` | Имя покупателя. |
| `phone` | Телефон покупателя (без валидации и коррекции). |
| `email` | E-mail покупателя (без валидации и коррекции). |
| `comment` | Произвольный комментарий к лиду. |
| `meta[xxx]` | Произвольное поле лида с названием `xxx`. |
| `utm_source` | Метка **UTM Source** на замену полученной из клика. |
| `utm_campaign` | Метка **UTM Campaign** на замену полученной из клика. |
| `utm_content` | Метка **UTM Content** на замену полученной из клика. |
| `utm_term` | Метка **UTM Term** на замену полученной из клика. |
| `utm_medium` | Метка **UTM Medium** на замену полученной из клика. |
| `subid` | Метка **SubID** на замену полученной из клика. |
| `customer` | Метка **Клиент** для отслеживания ID игроков или покупателей. |
| `adid` | Идентификатор рекламного перехода на замену полученному из клика. |
| `data1` | Произвольные **данные 1** на замену полученных из клика. |
| `data2` | Произвольные **данные 2** на замену полученных из клика. |
| `data3` | Произвольные **данные 3** на замену полученных из клика. |
| `data4` | Произвольные **данные 4** на замену полученных из клика. |
| `data5` | Произвольные **данные 5** на замену полученных из клика. |
| `stn` | Статус или список статусов, которые распознаются как **новый** лид. |
| `sth` | Статус или список статусов, которые распознаются как лид в **холде**. |
| `sta` | Статус или список статусов, которые распознаются как **подтверждение** лида. |
| `stc` | Статус или список статусов, которые распознаются как **отмена** лида. |
| `stt` | Статус или список статусов, которые распознаются как **треш**. |
| `ip` | IP-адрес лида. |
| `geo` | Двухбуквенный ISO-код страны лида. |
| `ua` | User-Agent лида для определения ОС и браузера. |

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже) |
| `id` | Числовой идентификатор лида, с которым выполнялись действия. |
| `create` | Если был создан новый лид - `true`, если был изменён существующий - `false`. |
| `stage` | Статус, в котором пребывает лид: `new`, `hold`, `approve`, `cancel`, `trash`. |

Коды ошибок:

- `access` - указанный клик или поток вам не принадлежит.
- `bad-click` - клик с таким идентификатором не найден.
- `bad-flow` - поток с таким идентификатором не найден.
- `db` - произошла системная ошибка работы с базой данных.
- `no-changes` - изменений не потребовалось, лид уже в нужном состоянии.
- `no-click` - не указаны ID клика и потока. 

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "id": 1337,
    "create": true,
    "stage": "new"
}
```

**Пример ответа сервера с ошибкой:**

```json
{
    "status": "error",
    "error": "no-changes"
}
```

<a id="spend"></a>
## Импорт расходов

**URL вебмастера**: `https://domain.com/api/tracker/spend.json?id={token}`

**URL команды**: `https://domain.com/api/gangs/spend.json?id={token}`

Функция задаёт цену клика для трафика по указанным условиям. Позволяет использовать функционал расчёта ROI. Данные могут передаваться как в GET, так и в POST-запросе. В запросе обязательно должны присутствовать параметры `cpc` или `cost` и хотя бы одно условие (даты, поток, UTM-метки).

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `cost` | Общая цена за все клики этого периода. |
| `cpc` | Цена за один клик. |
| `from` | Дата начала периода в формате `ГГГГ-ММ-ДД`, Unix Timestamp или любом другом, распознаваемом функцией `strtotime`. |
| `to` | Дата конца периода в формате `ГГГГ-ММ-ДД`, Unix Timestamp или любом другом, распознаваемом функцией `strtotime`. |
| `flow` | Символьный идентификатор потока. Можно передать массив идентификаторов. |
| `way` | Числовой идентификатор пути внутри потока. Можно передать массив идентификаторов. |
| `currency` | Трёхсимвольный ISO-код валюты цены клика, по умолчанию `usd`. |
| `geo` | Двухбуквенный ISO-код страны клика. |
| `domain` | Домен, на котором был зарегистрирован клик. |
| `utm_source` | Метка **UTM Source**, по которой был зарегистрирован клик. |
| `utm_campaign` | Метка **UTM Campaign**, по которой был зарегистрирован клик. |
| `utm_content` | Метка **UTM Content**, по которой был зарегистрирован клик. |
| `utm_term` | Метка **UTM Term**, по которой был зарегистрирован клик. |
| `utm_medium` | Метка **UTM Medium**, по которой был зарегистрирован клик. |
| `subid` | Метка **SubID**, по которой был зарегистрирован клик. |
| `customer` | Метка **Клиент**, по которой был зарегистрирован клик. |
| `valid` | Устанавливать цену только для валидных кликов: целевых кликов, которые прошли фильтр. |
| `unique` | Устанавливать цену только уникальных кликов. |

Вы также можете одновременно обновлять несколько ценников одним запросом, для этого объедините все запросы в массив `batch` и отправьте его через POST, например:

```json
{
    "batch": [
        {
            "flow": "face",
            "cost": 1984,
            "currency": "usd"
        },
        {
            "from": "2020-04-04 00:00:00",
            "to": "2020-04-07 23:59:59",
            "cpc": 1.337,
            "currency": "eur"
        }
    ]
}
```

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже) |
| `ok` | Количество успешных запросов на установку цены. Обычно, содержит ответ `ok=1` |
| `bad` | Количество неудачных запросов на установку цены. |

Коды ошибок:

- `empty` - нет данных для внесения в ценники.

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "ok": 1,
    "bad": 0
}
```

**Пример ответа сервера с ошибкой:**

```json
{
    "status": "error",
    "error": "empty"
}
```

<a id="templates"></a>
## Шаблоны постбеков

**URL**: `https://domain.com/api/tracker/templates.json?id={token}`

Функция возвращает справочник **шаблонов постбеков** — заготовок для CPA-сетей и партнёрских программ. Каждый шаблон содержит URL оффера и готовые строки запроса постбека, которыми партнёрская сеть должна вызывать ваш трекер, по одной на каждое конверсионное событие. Это те же заготовки, что показываются в селекторе «Шаблон сети» в редакторе потока. Функция не принимает параметров.

Список объединяет встроенный справочник (синхронизируется из сети AlterCPA) с вашими собственными шаблонами, созданными в настройках трекера; состав полей у них одинаковый.

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: всегда `ok`. |
| `data` | Объект шаблонов с ключами по числовому идентификатору шаблона (см. ниже). |

Каждый шаблон в поле `data` представлен ассоциативным массивом:

| Поле | Описание |
| --- | --- |
| `name` | Название CPA-сети / партнёрской программы. |
| `url` | URL оффера или лендинга шаблона. |
| `param` | Массив имён плейсхолдеров (`[[имя]]`), используемых в строках запроса постбека. |
| `pb` | Строка запроса **глобального** постбека. |
| `pbr` | Строка запроса постбека на **регистрацию**. |
| `pbd` | Строка запроса постбека на **депозит**. |
| `pbs` | Строка запроса постбека на **платёж RevShare**. |
| `pbn` | Строка запроса постбека на **новый лид**. |
| `pbh` | Строка запроса постбека на **холд**. |
| `pba` | Строка запроса постбека на **подтверждение**. |
| `pbc` | Строка запроса постбека на **отклонение**. |
| `pbt` | Строка запроса постбека на **треш**. |

Каждое значение `pb*` — это строка запроса без ведущего знака `?`. Чтобы получить финальный URL для партнёрской сети, добавьте её к базовому адресу постбека: `{postback}?{pb*}`, подставив макросы-плейсхолдеры `[[имя]]`, перечисленные в `param`. Присутствуют только поля, имеющие смысл для конкретного шаблона — у простого шаблона может быть только `pb`.

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "data": {
        "12": {
            "name": "Acme CPA",
            "url": "https://acme.example/offer?click=[[click]]",
            "param": [ "click", "status" ],
            "pb": "click=[[click]]&event=global",
            "pba": "click=[[click]]&event=approve",
            "pbc": "click=[[click]]&event=cancel"
        },
        "10001": {
            "name": "My own network",
            "url": "https://my.example/?c=[[click]]",
            "param": [ "click" ],
            "pb": "c=[[click]]"
        }
    }
}
```

<a id="networks"></a>
## Источники трафика

**URL**: `https://domain.com/api/tracker/networks.json?id={token}`

Функция возвращает справочник **источников трафика** (рекламных сетей). Каждая заготовка заранее заполняет метки UTM/SubID/данные потока, цену клика и валюту по умолчанию, а также исходящие URL постбеков, которые трекер отправляет обратно в рекламную сеть при каждой смене статуса лида. Это те же заготовки, что показываются в селекторе источника в редакторе потока. Функция не принимает параметров.

Список объединяет встроенный справочник (синхронизируется из сети AlterCPA) с вашими собственными источниками, созданными в настройках трекера; состав полей у них одинаковый.

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: всегда `ok`. |
| `data` | Объект источников трафика с ключами по числовому идентификатору источника (см. ниже). |

Каждый источник в поле `data` представлен ассоциативным массивом:

| Поле | Описание |
| --- | --- |
| `name` | Название источника трафика / рекламной сети. |
| `utms` | Шаблон значения метки **UTM Source**. |
| `utmc` | Шаблон значения метки **UTM Campaign**. |
| `utmn` | Шаблон значения метки **UTM Content**. |
| `utmt` | Шаблон значения метки **UTM Term**. |
| `utmm` | Шаблон значения метки **UTM Medium**. |
| `subid` | Шаблон значения метки **SubID**. |
| `data1`–`data5` | Шаблоны значений произвольных полей данных. |
| `hide1`–`hide6` | Шаблоны значений скрытых полей данных. |
| `cpc` | Цена клика по умолчанию. |
| `cur` | Валюта по умолчанию, по умолчанию `usd`. |
| `pbglobal` | **Глобальный** исходящий URL постбека. |
| `pbnew` | URL постбека при **новом** лиде. |
| `pbhold` | URL постбека при **холде**. |
| `pbapprove` | URL постбека при **подтверждении**. |
| `pbcancel` | URL постбека при **отклонении**. |
| `pbtrash` | URL постбека при **треше**. |
| `param` | Массив имён плейсхолдеров (`[[имя]]`), используемых в шаблонах значений. |

Все шаблоны значений могут содержать макросы-плейсхолдеры `[[имя]]`; трекер подставляет их при применении источника к потоку. Присутствуют только поля, настроенные для конкретного источника.

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "data": {
        "5": {
            "name": "Facebook Ads",
            "utms": "[[campaign]]",
            "subid": "[[adset]]",
            "cpc": "0.15",
            "cur": "usd",
            "pbglobal": "https://graph.facebook.com/...",
            "pbapprove": "https://graph.facebook.com/...?ev=Purchase",
            "param": [ "campaign", "adset" ]
        },
        "10002": {
            "name": "My own source",
            "cpc": "0.1",
            "cur": "usd"
        }
    }
}
```
