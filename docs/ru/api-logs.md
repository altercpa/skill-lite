# Журналы

API журналов даёт доступ на чтение к двум журналам трекера: журналу входящих API-запросов и журналу исходящих постбеков. Обе функции только читают данные. Записи возвращаются от новых к старым, постранично, в виде ассоциативного массива, ключом которого является числовой идентификатор записи. Журнал исходящих постбеков — тот же, что показан в подразделе «Исходящие постбеки» раздела «Журналы»; подраздел «Входящие постбеки» показывает постбек-запросы из журнала API-запросов.

Чьи записи вы увидите, зависит от рабочего пространства (`scope`):

- `user` (по умолчанию) — ваши собственные записи.
- `team` или `gang` — записи всех участников вашей команды; только для лидера команды. Передайте `user`, чтобы ограничить список одним участником команды.
- `admin` — записи всех пользователей; только для администратора. Передайте `user`, чтобы выбрать одного пользователя, или `gang`, чтобы выбрать всех участников одной команды.

<a id="logsrequests"></a>
## Журнал API-запросов

**URL вебмастера**: `https://domain.com/api/logs/requests.json?id={token}`

**URL команды**: `https://domain.com/api/logs/requests.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/logs/requests.json?id={token}&scope=admin`

Функция возвращает журнал входящих API-запросов: любое приложение и любая функция, а не только постбеки. Запрос попадает в журнал, только если на трекере включено журналирование запросов; запросы `ping` в журнал не попадают никогда. Для каждого запроса журнал хранит параметры, ответ, результат и данные клиента. Параметры можно передавать через GET или POST (`form-urlencoded` или JSON); параметр `scope` читается только из строки запроса, даже если сам запрос отправляется методом POST.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `scope` | Рабочее пространство: `user` (по умолчанию), `gang`/`team`, `admin`/`sys`. |
| `user` | Для `scope=gang` — ID участника команды; для `scope=admin` — ID пользователя. |
| `gang` | Для `scope=admin` — ID команды: записи всех участников команды (игнорируется, если указан `user`). |
| `from` | Дата начала в формате `YYYY-MM-DD`, с 00:00:00 включительно. |
| `to` | Дата окончания в формате `YYYY-MM-DD`, до 23:59:59 включительно. |
| `site` | Числовой идентификатор сайта. |
| `click` | Символьный идентификатор клика (или числовой идентификатор). |
| `lead` | Числовой идентификатор лида. |
| `flow` | Символьный идентификатор потока (или числовой идентификатор). |
| `err` | Фильтр по результату (см. ниже) |
| `page` | Номер страницы, начиная с `1`. По умолчанию `1`. |
| `show` | Количество записей на странице, от `1` до `1000`. По умолчанию `30`. |

Значения `err`:

- `-1` — только запросы, завершившиеся без ошибки.
- `-2` — только запросы, завершившиеся любой ошибкой.
- любое другое значение — только запросы с точно таким кодом ошибки (например, `access`).

Фильтры `site`, `click`, `lead` и `flow` находят запросы, в которых были переданы эти идентификаторы, например постбеки. У остальных запросов эти поля пустые.

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже) |
| `total` | Общее количество записей, подходящих под фильтры. |
| `page` | Номер текущей страницы. |
| `show` | Количество записей на странице. |
| `data` | Записи страницы с ключом-идентификатором записи, от новых к старым; пустой список, если ничего не найдено. Состав описан ниже. |

Коды ошибок:

- `scope` — запрошенное рабочее пространство вам недоступно (вы не лидер команды, не администратор, аккаунт заблокирован или при `scope=gang` в параметре `user` указан не участник вашей команды).

Каждая запись поля `data` представляет собой ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `id` | Числовой идентификатор записи. |
| `user` | Идентификатор пользователя, от имени которого выполнен запрос. |
| `time` | Время запроса в формате UNIX Timestamp. |
| `app` | Вызванное приложение. |
| `func` | Вызванная функция. |
| `ok` | `true`, если ответ не содержал ошибки, иначе `false`. |
| `error` | Код ошибки ответа, `false`, если ошибки не было. |
| `get` | GET-параметры запроса в виде ассоциативного массива. |
| `post` | POST-параметры запроса в виде ассоциативного массива; пустой список, если их не было. |
| `files` | Сведения о загруженных файлах; пустой список, если их не было. |
| `result` | Ответ на запрос. |
| `stage` | Стадия лида из ответа на постбек-запрос, `false`, если в ответе её нет. |
| `ip` | IP-адрес клиента, `false`, если неизвестен. |
| `geo` | Двухбуквенный ISO-код страны клиента, `false`, если неизвестна. |
| `ua` | User Agent клиента, `false`, если неизвестен. |
| `os` | Название операционной системы клиента, `false`, если неизвестна. |
| `browser` | Название браузера клиента, `false`, если неизвестен. |
| `site` | Числовой идентификатор сайта, `0`, если в запросе его не было. |
| `click` | Символьный идентификатор клика, `false`, если в запросе его не было. |
| `lead` | Числовой идентификатор лида, `0`, если в запросе его не было. |
| `flow` | Символьный идентификатор потока, `false`, если в запросе его не было. |

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "total": 1,
    "page": 1,
    "show": 30,
    "data": {
        "1042": {
            "id": 1042,
            "user": 13,
            "time": 1760698500,
            "app": "tracker",
            "func": "postback",
            "ok": true,
            "error": false,
            "get": {
                "click": "ca1337",
                "status": "approve"
            },
            "post": [],
            "files": [],
            "result": {
                "status": "ok",
                "stage": "approve"
            },
            "stage": "approve",
            "ip": "203.0.113.7",
            "geo": "de",
            "ua": "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0 Safari/537.36",
            "os": "Linux",
            "browser": "Chrome",
            "site": 0,
            "click": "ca1337",
            "lead": 77,
            "flow": "ef1c"
        }
    }
}
```

**Пример ответа сервера с ошибкой:**

```json
{
    "status": "error",
    "error": "scope"
}
```

## Журнал исходящих постбеков

**URL вебмастера**: `https://domain.com/api/logs/postbacks.json?id={token}`

**URL команды**: `https://domain.com/api/logs/postbacks.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/logs/postbacks.json?id={token}&scope=admin`

Функция возвращает журнал исходящих постбеков — запросов, которые трекер отправлял на внешние адреса при смене статуса лида. Для каждого постбека журнал хранит адрес, тело запроса, ответ удалённого сервера и время запроса. Параметры можно передавать через GET или POST (`form-urlencoded` или JSON); параметр `scope` читается только из строки запроса, даже если сам запрос отправляется методом POST.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `scope` | Рабочее пространство: `user` (по умолчанию), `gang`/`team`, `admin`/`sys`. |
| `user` | Для `scope=gang` — ID участника команды; для `scope=admin` — ID пользователя. |
| `gang` | Для `scope=admin` — ID команды: записи всех участников команды (игнорируется, если указан `user`). |
| `from` | Дата начала в формате `YYYY-MM-DD`, с 00:00:00 включительно. |
| `to` | Дата окончания в формате `YYYY-MM-DD`, до 23:59:59 включительно. |
| `lead` | Числовой идентификатор лида. |
| `site` | Числовой идентификатор сайта. |
| `event` | Событие постбека (см. ниже) |
| `flow` | Символьный идентификатор потока. |
| `click` | Символьный идентификатор клика. |
| `page` | Номер страницы, начиная с `1`. По умолчанию `1`. |
| `show` | Количество записей на странице, от `1` до `1000`. По умолчанию `30`. |

Значения `event`:

- `1` — Глобальный.
- `2` — Новый.
- `3` — Холд.
- `4` — Аппрув.
- `5` — Отмена.
- `6` — Треш.

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже) |
| `total` | Общее количество записей, подходящих под фильтры. |
| `page` | Номер текущей страницы. |
| `show` | Количество записей на странице. |
| `data` | Записи страницы с ключом-идентификатором записи, от новых к старым; пустой список, если ничего не найдено. Состав описан ниже. |

Коды ошибок:

- `scope` — запрошенное рабочее пространство вам недоступно (вы не лидер команды, не администратор, аккаунт заблокирован или при `scope=gang` в параметре `user` указан не участник вашей команды).

Каждая запись поля `data` представляет собой ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `id` | Числовой идентификатор записи. |
| `user` | Идентификатор владельца лида. |
| `time` | Время отправки постбека в формате UNIX Timestamp. |
| `flow` | Символьный идентификатор потока, `false`, если его нет. |
| `click` | Символьный идентификатор клика, `false`, если его нет. |
| `lead` | Числовой идентификатор лида. |
| `site` | Числовой идентификатор сайта. |
| `event` | Событие постбека (см. выше) |
| `eventname` | Название события на языке вашего интерфейса, `false`, если неизвестно. |
| `url` | Адрес, на который отправлен постбек. |
| `post` | Тело запроса в том виде, в котором оно отправлено, `false` для запроса без тела. |
| `header` | Дополнительные заголовки запроса, по одному в строке; `false`, если их не было. |
| `result` | Ответ удалённого сервера. |
| `code` | HTTP-статус ответа удалённого сервера; `0`, если ответа не было. |
| `ok` | `true`, если статус от `200` до `399`, иначе `false`. |
| `timer` | Длительность запроса в секундах. |
| `json` | `true`, если тело запроса отправлено в формате JSON. |

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "total": 1,
    "page": 1,
    "show": 30,
    "data": {
        "518": {
            "id": 518,
            "user": 13,
            "time": 1760698510,
            "flow": "ef1c",
            "click": "ca1337",
            "lead": 77,
            "site": 0,
            "event": 4,
            "eventname": "Аппрув",
            "url": "https://example.com/pb?click=ca1337&status=approve",
            "post": false,
            "header": false,
            "result": "OK",
            "code": 200,
            "ok": true,
            "timer": 0.412,
            "json": false
        }
    }
}
```

**Пример ответа сервера с ошибкой:**

```json
{
    "status": "error",
    "error": "scope"
}
```
