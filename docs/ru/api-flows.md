# Потоки и пути

Раздел API `flows` предоставляет полный набор операций для управления **потоками** и **путями** — ключевыми сущностями TDS-модуля трекера. Через этот API вы можете получать списки и детали потоков, создавать и клонировать их, редактировать настройки, добавлять и копировать пути, а также удалять потоки и пути. Функции работают в трёх пространствах: вебмастера (`user`), команды (`gang`) и администратора (`admin`).

Параметр `scope` передаётся **только через GET** — даже если основной запрос отправляется методом POST или в формате JSON. Параметры `user` и `gang` могут передаваться как в GET, так и в POST.

Статистика по кликам и лидам, накопленная по потоку или пути, **не удаляется** при их удалении — это намеренное поведение для сохранения финансовых отчётов.

Для получения статистики по потокам используйте функции раздела [Статистика трекера](api-stats.md). Управление фильтрами клоаки, которые привязываются к потокам, описано в разделе [Фильтрация трафика](api-filter.md). Управление сайтами хранилища, используемыми в путях, — в разделе [Хранилище сайтов](api-sites.md). Управление доменами, привязываемыми к потокам, — в разделе [Паркованные домены](api-domains.md).

## Список потоков

**URL вебмастера**: `https://domain.com/api/flows/list.json?id={token}`

**URL команды**: `https://domain.com/api/flows/list.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/flows/list.json?id={token}&scope=admin`

Возвращает постраничный список потоков с фильтрацией по различным критериям. В режиме администратора без указания фильтров `user` или `gang` функция возвращает все потоки системы.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `flow` | Символьный код потока — фильтр по конкретному потоку. |
| `fid` | Числовой ID потока — фильтр по конкретному потоку. Используется, если `flow` не задан. |
| `uid` | Псевдоним `fid` — числовой ID потока. |
| `user` | Фильтр по владельцу (для scope `admin` — фильтр по любому пользователю; для scope `gang` — фильтр в рамках участников команды). |
| `gang` | Фильтр по команде. Доступен только для scope `admin`. |
| `domain` | Числовой ID паркованного домена — фильтр по домену, привязанному к потоку. |
| `search` | Полнотекстовый поиск по названию потока. |
| `page` | Номер страницы (≥ 1). По умолчанию — 1. |
| `show` | Количество потоков на странице. Если передать 0 — будет использовано значение 100. По умолчанию — 100. |
| `short` | Сокращённый формат ответа — только основные поля (см. ниже). По умолчанию — false. |

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже). |
| `total` | Общее количество потоков, соответствующих фильтру. |
| `page` | Текущая страница. |
| `show` | Размер страницы. |
| `data` | Ассоциативный массив потоков, где ключ — числовой ID потока. Состав полей разобран далее. |

Коды ошибок:

- `scope` — неверное значение параметра `scope` или недостаточно прав для указанного пространства.
- `unpaid` — активная подписка отсутствует (только для scope `user` и `gang`).

Состав элемента в поле `data` при `short=false` (полный формат):

| Поле | Описание |
| --- | --- |
| `id` | Числовой ID потока. |
| `user` | ID владельца потока. |
| `gang` | ID команды (0, если поток личный). |
| `name` | Название потока. |
| `domain` | ID паркованного домена (0, если не привязан). |
| `code` | Символьный hex-код потока. |
| `url` | Полный URL потока. Если к потоку привязан домен, код в URL опускается. |
| `algo` | Режим оптимизации распределения трафика (0..8). |
| `direct` | Доля трафика на лучший путь в процентах (0..100). |
| `rotor` | Режим ротора (0 или 1). |
| `template` | ID шаблона трекера (0, если не задан). |
| `nostore` | Режим хранения данных о кликах (0/1/2). |
| `simple` | Упрощённый режим потока (true/false). |
| `autourl` | Автоматическое построение URL (true/false). |
| `nocookie` | Режим работы без cookie (0/1/2). |
| `pixel` | Пиксельный трекинг включён (true/false). |
| `filter` | Настройки фильтрации потока (объект, см. ниже). |
| `tags` | UTM-метки и дополнительные поля (объект, см. ниже). |
| `stats` | Агрегированная статистика (объект, см. ниже). |
| `postback` | Настройки постбеков (объект, см. ниже). |

Состав объекта `filter`:

| Поле | Описание |
| --- | --- |
| `filter` | ID фильтра клоаки (0, если не задан). |
| `bots` | Фильтрация ботов включена (true/false). |
| `filters` | Расширенная фильтрация включена (true/false). |
| `geo` | Гео-фильтрация включена (true/false). |
| `lang` | Фильтрация по языку браузера включена (true/false). |
| `adid` | Фильтрация по наличию рекламного идентификатора включена (true/false). |
| `geos` | Массив ISO-кодов стран для гео-фильтра. |
| `url` | Фильтрация по URL включена (true/false). |
| `site` | ID сайта для трафикбека (0, если не задан). |
| `spath` | Путь к белому сайту в хранилище (false, если не задан). |
| `method` | Метод трафикбека. |

Состав объекта `tags`:

| Поле | Описание |
| --- | --- |
| `source` | UTM-метка source (false, если не задана). |
| `campaign` | UTM-метка campaign (false, если не задана). |
| `content` | UTM-метка content (false, если не задана). |
| `term` | UTM-метка term (false, если не задана). |
| `medium` | UTM-метка medium (false, если не задана). |
| `subid` | SubID (false, если не задан). |
| `data1` | Дополнительное поле data1 (false, если не задано). |
| `data2` | Дополнительное поле data2 (false, если не задано). |
| `cpc` | Цена клика (false, если не задана). |
| `cur` | Валюта, трёхбуквенный код (например, `usd`). |

Состав объекта `stats`:

| Поле | Описание |
| --- | --- |
| `cr` | Конверсия (conversion rate). |
| `epc` | Заработок за клик (earnings per click). |
| `appr` | Процент подтверждённых лидов. |
| `money` | Суммарный заработок. |

Состав объекта `postback`:

| Поле | Описание |
| --- | --- |
| `global` | URL постбека на любое изменение статуса (false, если не задан). |
| `new` | URL постбека при создании нового лида (false, если не задан). |
| `hold` | URL постбека на переход в статус «холд» (false, если не задан). |
| `approve` | URL постбека на подтверждение лида (false, если не задан). |
| `cancel` | URL постбека на отмену лида (false, если не задан). |
| `trash` | URL постбека на отправку в корзину (false, если не задан). |

При `short=true` состав элемента `data` сокращён:

| Поле | Описание |
| --- | --- |
| `id` | Числовой ID потока. |
| `user` | ID владельца потока. |
| `gang` | ID команды (0, если поток личный). |
| `name` | Название потока. |
| `code` | Символьный hex-код потока. |
| `url` | Полный URL потока. |

## Получение потока

**URL вебмастера**: `https://domain.com/api/flows/get.json?id={token}`

**URL команды**: `https://domain.com/api/flows/get.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/flows/get.json?id={token}&scope=admin`

Возвращает детальную карточку потока вместе со списком всех его путей.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `flow`* | Символьный код потока. Обязателен, если не передан `fid`. |
| `fid`* | Числовой ID потока. Обязателен, если не передан `flow`. |
| `user` | ID пользователя для scope `gang` (фильтр в рамках команды) или `admin`. |
| `gang` | ID команды для scope `admin`. |

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже). |
| `data` | Объект с данными потока. Состав полей разобран далее. |

Коды ошибок:

- `scope` — неверное значение параметра `scope` или недостаточно прав.
- `unpaid` — активная подписка отсутствует.
- `no-id` — не передан ни `flow`, ни `fid`.
- `bad-id` — поток с указанным идентификатором не найден.
- `access-denied` — поток принадлежит другому пользователю (scope `user`) или другой команде (scope `gang`).
- `wrong-user` — scope `gang`, указан параметр `user`, но владелец потока — другой пользователь.

Состав поля `data`:

Поле `data` содержит полную структуру потока (все поля, описанные в [flows/list](#flowslist), включая расширенный набор в `tags`: `data1..data5`, `hide1..hide6`) плюс дополнительное поле `ways`.

| Поле | Описание |
| --- | --- |
| `id` | Числовой ID потока. |
| `user` | ID владельца потока. |
| `gang` | ID команды (0, если поток личный). |
| `name` | Название потока. |
| `domain` | ID паркованного домена (0, если не привязан). |
| `code` | Символьный hex-код потока. |
| `url` | Полный URL потока. |
| `gif` | HTML-тег пиксельного изображения для трекинга (`<img ...>`). |
| `algo` | Режим оптимизации (0..8). |
| `direct` | Доля трафика на лучший путь (0..100). |
| `rotor` | Режим ротора (0 или 1). |
| `template` | ID шаблона (0, если не задан). |
| `nostore` | Режим хранения кликов (0/1/2). |
| `simple` | Упрощённый режим (true/false). |
| `autourl` | Авто-URL (true/false). |
| `nocookie` | Режим без cookie (0/1/2). |
| `pixel` | Пиксельный трекинг (true/false). |
| `filter` | Настройки фильтрации (объект, см. [flows/list](#flowslist)). |
| `tags` | UTM-метки и дополнительные поля, включая `data1..data5`, `hide1..hide6`, `cpc`, `cur`. |
| `stats` | Агрегированная статистика: `cr`, `epc`, `appr`, `money`. |
| `postback` | Настройки постбеков (см. [flows/list](#flowslist)). |
| `ways` | Ассоциативный массив путей потока, где ключ — числовой ID пути (см. ниже). |

Состав элемента в поле `ways`:

| Поле | Описание |
| --- | --- |
| `id` | Числовой ID пути. |
| `name` | Название пути. |
| `active` | Путь активен (true/false). |
| `nostore` | Режим хранения кликов пути (0/1). |
| `prio` | Приоритет пути. |
| `site` | ID сайта хранилища (0, если не задан). |
| `spath` | Путь к сайту в хранилище (false, если не задан). |
| `url` | URL первого шага пути. |
| `method` | Метод работы пути (0..9, см. [flows/create](#flowscreate)). |
| `nxsite` | ID сайта второго шага (0, если не задан). |
| `nxpath` | Путь к сайту второго шага в хранилище. |
| `nxurl` | URL второго шага. |
| `nxmethod` | Метод второго шага. |
| `pos` | Вес пути (≥ 0). |
| `w1`..`w7` | Активность по дням недели: w1 — понедельник, w7 — воскресенье (true/false). |
| `from` | Начало рабочего периода (время). |
| `to` | Конец рабочего периода (время). |
| `tz` | Часовой пояс для расписания. |
| `shift` | Сдвиг расписания. |
| `limit` | Период капа (0..7). |
| `cap` | Лимит лидов (0 — безлимит). |
| `goal` | Цель для расчёта капа. |
| `status` | Статусы лидов, учитываемые в капе. |
| `geo` | Массив ISO-кодов разрешённых стран. |
| `nogeo` | Массив ISO-кодов запрещённых стран. |
| `mobile` | Фильтр по типу устройства (0..4). |
| `bots` | Пропускать ботов (true/false). |
| `adid` | Фильтр по рекламному идентификатору (true/false). |
| `filter` | ID фильтра клоаки для пути (0, если не задан). |
| `filters` | Расширенная фильтрация для пути (true/false). |
| `lang` | Фильтрация по языку (true/false). |
| `uwl` | Белый список слов в URL реферера (массив). |
| `ubl` | Чёрный список слов в URL реферера (массив). |
| `cr` | Конверсия пути. |
| `epc` | Заработок за клик для пути. |
| `appr` | Процент аппрувов для пути. |
| `money` | Суммарный заработок пути. |
| `crg` | JSON-карта «страна → конверсия». |
| `epcg` | JSON-карта «страна → EPC». |
| `hide1`..`hide6` | Скрытые поля пути. |

## Файл клиента TDS

**URL вебмастера**: `https://domain.com/api/flows/file.json?id={token}`

**URL команды**: `https://domain.com/api/flows/file.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/flows/file.json?id={token}&scope=admin`

Формирует готовый PHP-файл клиента TDS для встраивания в сторонний сервер. Файл (`index.php`) содержит клиентскую библиотеку и вызов функции `tds()` с параметрами вашего потока.

Для скачивания файла-вложения передайте параметр `format=raw` прямо в URL (`api/flows/file.raw`). В этом случае запрос завершается немедленно после отдачи файла и не логируется. В стандартном JSON-формате содержимое файла возвращается как строка в поле `data`.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `flow`* | Символьный код потока. Обязателен, если не передан `fid`. |
| `fid`* | Числовой ID потока. Обязателен, если не передан `flow`. |
| `user` | ID пользователя для scope `gang` или `admin`. |
| `gang` | ID команды для scope `admin`. |

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже). |
| `data` | Содержимое PHP-файла клиента в виде строки (только при JSON-формате). |

При запросе с `format=raw` ответ представляет собой файл-вложение:

```
Content-type: text/plain
Content-Disposition: attachment; filename=index.php
```

Коды ошибок:

- `scope` — неверное значение параметра `scope` или недостаточно прав.
- `unpaid` — активная подписка отсутствует.
- `no-id` — не передан ни `flow`, ни `fid`.
- `bad-id` — поток с указанным идентификатором не найден.
- `access-denied` — поток принадлежит другому пользователю или команде.
- `wrong-user` — владелец потока не совпадает с переданным `user` (scope `gang`).

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "data": "<?php\n/* AlterCPA TDS client */\n..."
}
```

**Пример ответа сервера с ошибкой:**

```json
{
    "status": "error",
    "error": "no-id"
}
```

## Текущие капы по путям

Возвращает состояние лимитов лидов (капов) по всем путям потока. Данные кешируются на 60 секунд — это позволяет использовать функцию для частого мониторинга без избыточной нагрузки на базу данных.

| Поле | Описание |
| --- | --- |
| `flow`* | Символьный код потока. Обязателен, если не передан `fid`. |
| `fid`* | Числовой ID потока. Обязателен, если не передан `flow`. |
| `user` | ID пользователя для scope `gang` или `admin`. |
| `gang` | ID команды для scope `admin`. |

Результатом выполнения функции является ассоциативный массив:

Коды ошибок:

- `scope` — неверное значение параметра `scope` или недостаточно прав.
- `unpaid` — активная подписка отсутствует.
- `no-id` — не передан ни `flow`, ни `fid`.
- `bad-id` — поток с указанным идентификатором не найден.
- `access-denied` — поток принадлежит другому пользователю или команде.
- `wrong-user` — владелец потока не совпадает с переданным `user` (scope `gang`).

## Создание потока

**URL вебмастера**: `https://domain.com/api/flows/create.json?id={token}`

**URL команды**: `https://domain.com/api/flows/create.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/flows/create.json?id={token}&scope=admin`

Создаёт новый поток с одним стартовым путём. Для scope `gang` параметр `user` обязателен — поток создаётся от имени указанного участника команды. В scope `user` владелец определяется автоматически по токену.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `name`* | Название потока. Обязательный параметр. |
| `url`* | URL первого пути. Обязателен, если не передан `site`. |
| `site`* | ID сайта хранилища для первого пути. Обязателен, если не передан `url`. |
| `user` | ID владельца. Обязателен для scope `gang` и `admin`. В scope `user` подставляется автоматически. |
| `gang` | ID команды для scope `admin`. |
| `method` | Метод работы первого пути (см. ниже). По умолчанию — 0. |
| `simple` | Упрощённый режим: 1 — включить. В этом режиме единственный путь получает имя `Default`. По умолчанию — 0. |

Описание значений метода (`method`):

- `0` — HTTP 302 (временный редирект).
- `1` — HTTP 301 (постоянный редирект).
- `2` — JavaScript redirect.
- `3` — Iframe.
- `4` — Proxy (серверный проксирующий запрос).
- `5` — cURL (серверная загрузка страницы).
- `6` — Local (локальный файл на хранилище).
- `7` — Error (возврат ошибки).
- `8` — Blank (пустая страница).
- `9` — JS Go (переход через JavaScript).

Результатом выполнения функции является ассоциативный массив:

| Поле | Описание |
| --- | --- |
| `status` | Результат выполнения операции: `ok` в случае успешного выполнения, `error` в случае ошибки. |
| `error` | Код ошибки для статуса `error` (см. ниже). |
| `data` | Полная структура созданного потока, включая поле `ways` с первым путём (см. [flows/get](#flowsget)). |

Коды ошибок:

- `scope` — неверное значение параметра `scope` или недостаточно прав.
- `unpaid` — активная подписка отсутствует.
- `user-required` — параметр `user` не передан (обязателен для scope `admin` и `gang`).
- `limit-reached` — достигнут лимит количества потоков по тарифу.
- `no-name` — не указано название потока.
- `no-way` — не указан ни `url`, ни `site` для первого пути.
- `create` — ошибка при записи в базу данных.

**Пример успешного ответа сервера:**

```json
{
    "status": "ok",
    "data": {
        "id": 12346,
        "user": 7,
        "gang": 0,
        "name": "New Flow",
        "code": "ab3d",
        "url": "https://click.example.com/ab3d",
        "ways": {
            "680": {
                "id": 680,
                "name": "Default",
                "active": true,
                "url": "https://lp.example.com",
                "method": 0
            }
        }
    }
}
```

```json

    "status": "error",
    "error": "no-name"
}
```

## Изменение настроек пути

**URL вебмастера**: `https://domain.com/api/flows/edit.json?id={token}`

**URL команды**: `https://domain.com/api/flows/edit.json?id={token}&scope=gang`

**URL администратора**: `https://domain.com/api/flows/edit.json?id={token}&scope=admin`

Частично обновляет поля пути. Передайте только те поля, которые нужно изменить — остальные останутся без изменений. Поле `name` не может быть явно очищено. Сайты хранилища (`site`, `nxsite`) проверяются на принадлежность текущему пользователю или команде; если доступа нет — поле молча пропускается.

Функция может принимать на вход следующие параметры:

| Поле | Описание |
| --- | --- |
| `way`* | Числовой ID пути. Обязательный параметр. |
| `user` | ID пользователя для scope `gang` или `admin`. |
| `gang` | ID команды для scope `admin`. |
| `name` | Новое название пути. Не может быть пустым. |
| `site` | ID сайта хранилища первого шага. Проверяется на доступность. |
| `url` | URL первого шага. |

| `method` | Метод работы первого шага (см. [flows/create](#flowscreate)). |
| `nostore` | Режим хранения кликов пути (0 или 1). |

| `prio` | Приоритет пути (от -9 до 9). |

| `tz` | Часовой пояс расписания (например, `Europe/Moscow`). |
| `limit` | Период капа (0..7). |
| `cap` | Лимит лидов (0 — безлимит). |
| `goal` | Цель для расчёта капа. |
| `status` | Статусы лидов, учитываемые в капе. |

| `mobile` | Фильтр по типу устройства (0..4). |
| `bots` | Пропускать ботов (0 или 1). |
| `adid` | Фильтр по рекламному идентификатору (0 или 1). |

| `ubl` | Чёрный список слов в URL реферера (строка, слова разделены переносом строки). |

**URL администратора**: `https://domain.com/api/flows/del.json?id={token}&scope=admin`

Удаляет отдельный путь из потока. Статистика по кликам и лидам, накопленная по данному пути, **не удаляется** и остаётся доступна в отчётах. Удаление последнего пути в потоке не блокируется — поток без путей не сможет принимать трафик.

Функция может принимать на вход следующие параметры:

| `error` | Код ошибки для статуса `error` (см. ниже). |
