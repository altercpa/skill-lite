# Встроенный трекер

Наш сервис фильтрации трафика позволяет отслеживать успешность работы ваших фильтров и целевые действия по сайтам. Вам доступны два варианта трекинга - упрощенный мини-трекер внутри самих кампаний и полноценный трекер в отдельном разделе.

## Мини-трекер

Каждая кампания фильтрации может подсчитывать количество кликов и лидов, которые через неё прошли. Это простейший счётчик, который не учитывает изменения лидов, не сохраняет их данные, исключительно подсчитывая количество.

В разделе фильтров используются следующие колонки:

- **Общее количество визитов**, которые были обработаны фильтром.
- **Количество целевых визитов**, используется для дальнейших расчётов.
- **Количество мусорных визитов**, отклонённых фильтром.
- **Общее количество лидов** или действий на целевом сайте.
- **Количество принятых лидов** или удачных действий.
- **Количество отклоненных лидов** или неудачных действий.
- **Общая сумма заработка** на принятых лидах.
- **CR**: конверсия - соотношение общего числа лидов к целевым визитам.
- **EPC**: доход на клик - соотношение суммы заработка к целевым визитам.
- **Аппрув**: соотношение количества принятых лидов к их общему числу.

Чтобы подключить мини-трекер к партнёрской сети, нужно настроить постбеки на создание лида, аппрув и отклонение лида. Готовые постбеки вы можете найти, нажав на "Настройки" вашей кампании фильтрации и прокрутив страницу до конца.

Функция постбека имеет три параметра:

- `uid` - идентификатор вашей кампании фильтрации.
- `status` - статус лида (`new`, `approve`, `cancel`).
- `payout` - сумма за лид (учитывается только для статуса `approve`).

> **Очень важно!** Эти постбеки не умеют работать с дублями или некорректными отправками. Каждый раз, как вызывается постбек, он увеличивает счётчик количества лидов в выбранном статусе. Добавляйте постбеки только в те статусы на стороне партнёрской сети, по которым отправка не пройдёт несколько раз.

## Полноценный трекер

Вы можете использовать полноценный трекер AlterCPA Lite прямо внутри нашего сервиса фильтрации трафика. Он располагается в разделе "Трекер" главного меню:

- **[Потоки](/track-flows)**: здесь настраиваются ваши кампании трекинга и сплит-тесты.
- **[Лиды](/track-leads)**: в этом разделе собираются данные о ваших лидах.
- **[Статистика](/track-stats)**: в этом разделе собирается сводная статистика по лидам и кликам.
- **[Домены](/track-domain)**: с помощью этого инструмента паркуются домены для трафика.
- **[Сайты](/track-sites)**: этот раздел открывает работу с локальными сайтами.

Трекер предоставляет вам полноценные инструменты для работы с трафиком:

- Встроенные простые механизмы [фильтрации трафика](filter.md) и возможность подключения потоков к полноценным кампаниям фильтрации с глубокой аналитикой визитов.
- Умное [сплит-тестирование](split.md) без ограничения на количество путей и гибкими настройками фильтрации визитов.
- Расширенную [статистику](stats.md) с поддержкой целей и учётом UTM-меток.
- Парковку [доменов](domain.md) для заливки трафика с возможностью привязки к главной странице.
- Различные [методы работы](method.md) со ссылками, в том числе прокси-запросы и возможность работы в виде локального файла на вашем хостинге.
- Поддержку [локальных сайтов](sites.md) в вашем собственном хранилище.
