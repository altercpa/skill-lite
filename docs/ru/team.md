# Командная работа

Трекер позволяет пользователям самостоятельно организовываться в арбитражные команды. В рамках команды лидеру доступна общая статистика всех участников и выгрузка расходов для всей команды сразу.

## Правильная командная работа

Трекер предлагает крайне ограниченные инструменты для работы арбитражной команды. Для серьёзной автоматизации команды мы рекомендуем использовать другие продукты нашей компании - [AlterCPA Pro](https://www.altercpa.pro/ru/altercpa) или [Cloud](https://www.altercpa.pro/ru/cloud). Они имеют ряд важных преимуществ:

1. Полноценные офферы с готовым набором лендингов и прелендингов, гибкими настройками доступа и условий работы.
2. Подключение к рекламодателям и партнёрским сетям осуществляется на уровне системы, веб-мастер не имеет никакого доступа в личные кабинеты и к счетам партнёрских сетей.
3. Комиссии и отчисления настраиваются на уровне оффера, реальные суммы заработка не видны вашим сотрудникам.
4. Учёт финансов осуществляется автоматически, у каждого сотрудника формируется свой персональный счёт с его заработком и подробной аналитикой.
5. Всю команду можно разбивать на отделы (внутренние мини-команды) со своими ответственными руководителями и особым доступом к офферам.

## Как вступить в команду?

Попросите вашего лидера скинуть вам специальную ссылку входа. Откройте её и нажмите "Присоединиться". Перед этим обязательно войдите в трекер под своим логином и паролем.

> **Важно!** С момента вступления в команду все ваши клики и лиды будут доступны руководству команды. Любой трафик, который вы заливали до вступления в команду или после выхода из неё, доступен только вам.

## Создание арбитражной команды

Команду можно создать через вашего администратора, сообщив список пользователей и лидера, или самостоятельно. Перейдите в раздел "[Команда](/gang)" в навигационном меню, укажите название вашей будущей команды и нажмите "Создать".

После создания, вы можете пригласить пользователей войти в вашу арбитражную команду. Для этого отправьте им ссылку входа, по которой они присоединятся к команде.

> **Важно!** Командная статистика считается с момента вступления пользователя в команду и перестаёт считаться в момент его ухода. Все лиды и клики, которые были у пользователя до вступления в команду или после его ухода, недоступны тимлидам. Весь трафик, который пользователь лил за время работы в команде, остаётся доступным всегда.

Рекомендуется настроить свою команду, указав краткое описание и открыв нужные разделы.

- **Лидеры.** В команде может быть несколько тимлидов. Все они имеют одинаковые права доступа к статистике пользователей и управлению командой. В том числе, могут снимать других лидеров с должности.
- **Название команды.** Используется только для красоты на страничке команды.
- **Описание.** Отображается на странице команды. Рекомендуется указывать здесь правила работы, контакты руководителей и финансистов, ссылки на важные внутренние ресурсы и подобные сведения.
- **Показывать главную страницу.** Если убрать эту галочку, страница описания и списка участников будет скрыта от обычных членов команды.
- **Показывать список участников.** Если убрать эту галочку, на странице команды будет показываться только описание, указанное парой пунктов выше.
- **Общий доступ к статистике.** Разделы статистики всех участников команды становятся доступны всем участникам. Это может пригодится в обучающих командах, чтобы коллективно разбирать конкретные кейсы и ошибки.

При необходимости, вы также можете поменять ссылку входа, чтобы сделать старые отправленные ссылки недоступными. Менять ссылку можно в любой момент после вступления участников.

## Чёрные списки

При работе в составе арбитражной команды, вы можете использовать общие чёрные списки команды. По умолчанию, доступ к их редактированию есть только у тимлидов, но вы можете включить общий доступ всей команды в настройках.

Активные списки команды доступны для выбора всем её участникам. Списки по умолчанию автоматически активируются для всей команды так же, как и системные. Командные чёрные списки, выбранные по умолчанию, также доступны в трекере.

[Документация по чёрным спискам](blacklist.md)

## Статистика и аналитика

Лидеры команды получают доступ к командной аналитике. Она представлена в трёх разделах: лиды, клики и статистика. Каждый из разделов копирует соответствующий раздел личной статистики.

В фильтрах этих разделов добавляется дополнительное поле: пользователь. Вы можете выбрать конкретного участника команды и отфильтровать статистику по нему. Статистику по конкретному пользователю также можно открыть из списка участников. Для этого нажмите на кнопку статистики и выберите интересующий вас раздел.

[Документация по статистике](stats.md)

## Потоки пользователей

Лидеры команды могут просматривать и настраивать потоки своих пользователей. В разделе командных потоков показываются только те, которые пользователь создавал за время работы в команде. Чтобы создать новый поток, сперва выберите пользователя в поле поиска. Для создания потока, у пользователя или команды должны быть доступны соответсвующие лимиты.

[Документация по потокам](flows.md)

## Выгрузка расходов

Лидеры команды могут добавлять общие для всей команды выгрузки расходов. Это удобно, если доступ к финансовой статистике есть только у лидера. Все принципы работы идентичные индивидуальным выгрузкам.

[Документация по расходам](spend.md)

## Хранилище сайтов

Команда может работать с общим хранилищем сайтов для всех участников. Оно настраивается в разделе "Команда - Сайты" аналогично личному хранилищу. Если вы хотите сделать своё личное хранилище общим для всей команды, просто скопируйте его настройки.
Полезные фичи командного хранилища сайтов:

Командное хранилище заменяет персональные хранилища пользователей. Любой участник команды сможет добавлять и редактировать сайты, парковать домены к новому хранилищу. Неприятная деталь: если у участника было своё личное хранилище, доступ к нему пропадёт.
Тимлиды могут добавлять общие для всех сайты. Это позволяет подготовить одинаковые офферы на всех участников команды. Рядовые участники смогут выбрать сайты в путях, посмотреть статистику по ним, но не смогут их редактировать.
Тимлиды могут создать сайты для конкретных участников команды. Это позволяет техническим специалистам команды делать персональные лендинги, прелендинги и белые сайты. Как и общие сайты, они доступны в потоках, но недоступны участникам для редактирования.

**Важно!** Сайты пользователей внутри хранилища не изолированы друг от друга физически и лежат в общей папке. Не используйте командное хранилище для работы с чувствительными данными, потому что все участники команды имеют доступ к загрузке сайтов в PHP-файлами.
[Документация по сайтам](sites.md)

## API

Лидеры команды могут использовать API для всей команды. Это позволяет получать статистику лидов и кликов, отправлять статистику по расходам на всю команду. Но самое важное, это позволяет настраивать единый постбек на стороне рекламодателя, который будет работать с потоками всей команды.
