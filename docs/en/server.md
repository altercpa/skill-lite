# Advices for choosing a server

You can use any VPS on any virtualization system. System requirements depend on traffic volumes:

- **Up to 1000 clicks** per day (solo work) - any option will do, about $5 per month.
- **1000-10000 clicks** per day (small team) - server with 2-4 GB RAM, about $10-20 per month.
- **10000-50000 clicks** per day (hard work) - server with 4-8 GB RAM and 4 cores, from $20 per month.
- **From 50000 clicks** per day (affiliate networks) - multiple servers recommended.

**Recommended OS:** Debian 11
